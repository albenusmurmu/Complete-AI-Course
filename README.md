# 📌 Rules

### Rule 1 — Understand before moving on

Don't check a topic simply because you watched a video.

### Rule 2 — Build everything

Every major phase should produce something.

### Rule 3 — Don't become a tutorial collector

Use courses as resources, not as the destination.

### Rule 4 — GitHub everything

Every meaningful project should be documented and pushed to GitHub.

### Rule 5 — Learn production early

AI Engineering ≠ Prompt Engineering.

Real AI Engineering includes:

```text
Software
+
AI
+

+
Evaluation
+
Security
+
Production
```
